🚀 CÓMO PROBAR (3 PASOS)
════════════════════════════════════════════════════════════════════════════════

1️⃣  PROBAR TUTORIAL
   → Ejecuta el juego (F5)
   → Presiona "INICIAR"
   → El tutorial aparece automáticamente
   → Navega con flechas hasta "Sistema de Puertas NK-7"
   → Verifica que explica [F] para reparar y [Q] para hackear

2️⃣  PROBAR GUARDADO
   → Juega hasta un checkpoint
   → Sal al menú (ESC → Salir)
   → Botón "CARGAR" debe estar habilitado
   → Presiona "CARGAR"
   → Debe cargar tu progreso

3️⃣  PROBAR MÚLTIPLES SLOTS
   → Inicia 3 partidas diferentes (borra guardados anteriores)
   → Avanza diferente cantidad en cada una
   → Presiona "CARGAR" en menú
   → Debe aparecer selector con 3 opciones
   → Selecciona una y verifica que carga

🎮 CONTROLES AÑADIDOS AL TUTORIAL
════════════════════════════════════════════════════════════════════════════════

[F] - Reparar puertas dañadas (mantener)
      • Consume durabilidad de herramienta
      • 1-3 pasos según daño
      • Luz roja → naranja → verde

[Q] - Hackear puertas bloqueadas (mantener)
      • Consume energía del jugador
      • 2-4 segundos según dificultad
      • Panel apagado → activo → desbloqueado
