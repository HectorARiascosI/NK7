⚙️ CONFIGURACIÓN RÁPIDA
════════════════════════════════════════════════════════════════════════════════

PUERTA DAÑADA FÁCIL:
```gdscript
repair_steps = 1
repair_time_per_step = 1.5
tool_cost_per_step = 5
```

PUERTA DAÑADA DIFÍCIL:
```gdscript
repair_steps = 3
repair_time_per_step = 2.5
tool_cost_per_step = 15
```

PUERTA BLOQUEADA FÁCIL:
```gdscript
hack_time = 2.0
energy_cost = 15
```

PUERTA BLOQUEADA DIFÍCIL:
```gdscript
hack_time = 4.0
energy_cost = 30
```
