💾 SISTEMA DE GUARDADO - CAMBIOS DETALLADOS
════════════════════════════════════════════════════════════════════════════════

ARCHIVO: scripts/autoload/game_manager.gd

NUEVAS CONSTANTES:
──────────────────
const MAX_SAVE_SLOTS := 3        # Máximo de slots de guardado
var current_save_slot := 0       # Slot actual en uso

NUEVAS FUNCIONES:
─────────────────

1. save_game(slot: int = -1) -> bool
   ├─ Guarda en el slot especificado o el actual
   ├─ Formato: user://save_slot_0.dat, save_slot_1.dat, save_slot_2.dat
   ├─ Incluye: versión, nivel, checkpoint, muertes, tiempo, fecha
   └─ Retorna: true si guardó correctamente

2. load_game(slot: int = -1) -> bool
   ├─ Carga del slot especificado o el actual
   ├─ Restaura todo el progreso
   ├─ Carga el nivel automáticamente
   └─ Retorna: true si cargó correctamente

3. get_save_info(slot: int) -> Dictionary
   ├─ Obtiene información sin cargar el guardado
   ├─ Retorna: {exists, slot, level, checkpoint, deaths, time, date, timestamp}
   └─ Útil para mostrar lista de guardados

4. delete_save(slot: int) -> bool
   ├─ Elimina un slot de guardado
   └─ Retorna: true si eliminó correctamente

5. has_any_save() -> bool
   ├─ Verifica si existe algún guardado
   └─ Útil para habilitar/deshabilitar botón "Cargar"

FORMATO DE GUARDADO:
────────────────────
{
    "version": "1.0",
    "slot": 0,
    "current_level": 1,
    "current_checkpoint": 0,
    "levels_completed": [],
    "total_deaths": 0,
    "total_time": 0.0,
    "timestamp": 1234567890,
    "date_string": "2026-05-05 14:30:00"
}

🔄 FLUJO COMPLETO DEL SISTEMA
════════════════════════════════════════════════════════════════════════════════

NUEVA PARTIDA:
──────────────
1. Usuario presiona "INICIAR" en menú principal
2. GameManager.reset_progress()
3. GameManager.current_save_slot = 0
4. Se carga level_01.tscn
5. Tutorial se muestra automáticamente
6. Usuario aprende sobre puertas NK-7
7. Al completar checkpoint → GameManager.save_game()

CONTINUAR PARTIDA (1 guardado):
────────────────────────────────
1. Usuario presiona "CARGAR" en menú principal
2. Sistema detecta 1 guardado en slot X
3. GameManager.load_game(X)
4. Se carga el nivel guardado
5. Usuario continúa desde último checkpoint

CONTINUAR PARTIDA (múltiples guardados):
─────────────────────────────────────────
1. Usuario presiona "CARGAR" en menú principal
2. Sistema detecta múltiples guardados
3. Se muestra SaveSelector
4. Usuario ve lista de guardados con información
5. Usuario selecciona un slot
6. GameManager.load_game(slot_seleccionado)
7. Se carga el nivel guardado

GUARDADO AUTOMÁTICO:
────────────────────
- Al alcanzar checkpoint → GameManager.reach_checkpoint()
- Al completar nivel → GameManager.complete_level()
- Ambos llaman a GameManager.save_game()
- Se guarda en el slot actual (current_save_slot)

🚀 CÓMO PROBAR
════════════════════════════════════════════════════════════════════════════════

PROBAR TUTORIAL:
────────────────
1. Ejecuta el juego desde el menú principal
2. Presiona "INICIAR"
3. El tutorial aparecerá automáticamente
4. Navega con flechas o A/D
5. Busca la página "Sistema de Puertas NK-7"
6. Verifica que explica [F] y [Q]
7. Presiona TAB en cualquier momento para ver resumen

PROBAR GUARDADO:
────────────────
1. Inicia nueva partida
2. Avanza hasta un checkpoint
3. Verifica que se guardó (consola muestra mensaje)
4. Sal al menú principal (ESC → Salir)
5. Botón "CARGAR" debe estar habilitado
6. Presiona "CARGAR"
7. Debe cargar desde el checkpoint

PROBAR MÚLTIPLES SLOTS:
────────────────────────
1. Inicia 3 partidas diferentes
2. Avanza diferente cantidad en cada una
3. Sal al menú principal
4. Presiona "CARGAR"
5. Debe aparecer selector con 3 slots
6. Cada slot muestra información diferente
7. Selecciona uno y verifica que carga correctamente

📝 NOTAS IMPORTANTES
════════════════════════════════════════════════════════════════════════════════

1. COMPATIBILIDAD:
   - Los guardados antiguos (save_game.dat) NO son compatibles

   - Si tienes guardados antiguos, elimínalos manualmente

2. UBICACIÓN DE GUARDADOS:
   - Windows: %APPDATA%\Godot\app_userdata\NK7GDT\
   - Linux: ~/.local/share/godot/app_userdata/NK7GDT/
   - macOS: ~/Library/Application Support/Godot/app_userdata/NK7GDT/

3. TUTORIAL:
   - Solo se muestra una vez por sesión
   - Usa TAB para ver resumen de controles en cualquier momento
   - El tutorial se puede saltar con ESC

4. GUARDADO AUTOMÁTICO:
   - Se guarda automáticamente en checkpoints
   - Se guarda al completar niveles
   - NO se guarda al morir
