PATRÓN 7: ROMPECABEZAS DE SECUENCIA
════════════════════════════════════════════════════════════════════════════════

OBJETIVO: Resolver un puzzle de orden correcto

CONFIGURACIÓN:
┌─────────────────────────────────────────────────────────────────────────────┐
│ 5 Puertas en fila, cada una con un interruptor                              │
│                                                                              │
│ REGLA: Deben abrirse en orden específico (ej: 3-1-4-2-5)                    │
│                                                                              │
│ Si se abre en orden incorrecto:                                             │
│ - Todas las puertas se cierran                                              │
│ - Se electrifican temporalmente                                             │
│ - Jugador debe esperar 10 segundos                                          │
│                                                                              │
│ PISTAS:                                                                      │
│ - Números en las paredes                                                    │
│ - Colores de las luces                                                      │
│ - Símbolos en los paneles                                                   │
└─────────────────────────────────────────────────────────────────────────────┘

IMPLEMENTACIÓN:
```gdscript
var correct_sequence = [3, 1, 4, 2, 5]
var current_sequence = []

func _on_door_opened(door_id: int):
    current_sequence.append(door_id)
    
    if current_sequence.size() == correct_sequence.size():
        if current_sequence == correct_sequence:
            _unlock_exit()
        else:
            _reset_puzzle()
            _electrify_all_doors()

func _reset_puzzle():
    current_sequence.clear()
    for door in doors:
        door.close_door()

func _electrify_all_doors():
    for door in doors:
        door.electrify()
    
    await get_tree().create_timer(10.0).timeout
    
    for door in doors:
        door.de_electrify()
```

CONSEJOS DE DISEÑO GENERAL
════════════════════════════════════════════════════════════════════════════════

1. TELEGRAFÍA VISUAL
   - Usa colores de luz para indicar estado
   - Partículas para mostrar peligro
   - Animaciones claras para feedback

2. CURVA DE DIFICULTAD
   - Empieza fácil (1 paso, sin peligros)
   - Aumenta gradualmente (más pasos, electricidad)
   - Picos de dificultad en momentos clave

3. RECOMPENSAS PROPORCIONALES
   - Puertas difíciles → Mejores recompensas
   - Rutas opcionales → Recursos extra
   - Desafíos de timing → Logros/achievements

4. VARIEDAD
   - Mezcla diferentes tipos de puertas
   - Combina con otros obstáculos
   - Alterna entre acción y puzzle

5. RESPETO AL JUGADOR
   - Siempre hay una solución
   - Checkpoints antes de secciones difíciles
   - Recursos suficientes (pero no excesivos)

6. TESTING
   - Juega tu nivel completo varias veces
   - Observa a otros jugadores
   - Ajusta basándote en feedback

MÉTRICAS RECOMENDADAS
════════════════════════════════════════════════════════════════════════════════

TIEMPO DE REPARACIÓN:
- Tutorial: 1.0-1.5 segundos por paso
- Normal: 2.0 segundos por paso
- Difícil: 2.5-3.0 segundos por paso

TIEMPO DE HACKEO:
- Fácil: 2.0 segundos
- Normal: 3.0 segundos
- Difícil: 4.0-5.0 segundos

COSTE DE DURABILIDAD:
- Tutorial: 5 puntos por paso
- Normal: 10 puntos por paso
- Difícil: 15-20 puntos por paso

AUTO-CIERRE:
- Generoso: 5.0+ segundos
- Normal: 3.0-4.0 segundos
- Desafiante: 2.0-2.5 segundos
- Extremo: 1.0-1.5 segundos

DAÑO ELÉCTRICO:
- Leve: 10-15 puntos
- Normal: 20-25 puntos
- Severo: 30-40 puntos
- Letal: 50+ puntos
